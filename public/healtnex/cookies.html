01

¿Qué son las cookies?

Las cookies son pequeños archivos de texto que los sitios web y aplicaciones almacenan en tu dispositivo cuando los visitas o usas. Se usan para recordar preferencias, mantener sesiones activas, analizar el uso y personalizar la experiencia.

Además de las cookies tradicionales (propias de entornos web), las aplicaciones móviles como Healtnex utilizan tecnologías equivalentes como el almacenamiento local del dispositivo (AsyncStorage), identificadores de dispositivo y SDKs de terceros que cumplen funciones similares.

02

¿Healtnex usa cookies?

Healtnex es una aplicación móvil nativa para Android, por lo que no utiliza cookies de navegador en el sentido tradicional. Sin embargo, usa tecnologías equivalentes con las mismas finalidades:

  • Almacenamiento local (AsyncStorage): para guardar la sesión del usuario y sus preferencias sin necesidad de volver a iniciar sesión.
  • Tokens JWT: para autenticar de forma segura las solicitudes al servidor.
  • SDKs de terceros: Firebase Analytics y Google AdMob, que pueden recopilar identificadores de dispositivo y datos de uso.
Al usar Healtnex, aceptas el uso de estas tecnologías conforme a esta Política y a nuestra Política de Privacidad.
03

Tecnologías de Almacenamiento Propias

CGB Technologies utiliza las siguientes tecnologías de almacenamiento propio en Healtnex:

AsyncStorage — Sesión y preferencias Guarda tu token de sesión (JWT) localmente en el dispositivo para que no tengas que iniciar sesión cada vez que abres la app. También almacena preferencias de la interfaz como el módulo activo o el estado de notificaciones. Esta información permanece en tu dispositivo y no se comparte con terceros.
Token JWT — Autenticación Cuando inicias sesión, el servidor genera un token JWT que se almacena en tu dispositivo. Este token se envía en cada solicitud al servidor para verificar tu identidad de forma segura. Expira automáticamente tras un período de inactividad.

Estas tecnologías son estrictamente necesarias para el funcionamiento de la App. Sin ellas, no es posible mantener la sesión activa ni usar Healtnex correctamente.

04

Cookies y SDKs de Terceros

Healtnex integra servicios de terceros que pueden recopilar datos de forma independiente bajo sus propias políticas de privacidad. CGB Technologies no controla el comportamiento de estos servicios ni los datos que recopilan directamente.

Los servicios de terceros integrados en Healtnex son:

  • Google Firebase (Analytics, Cloud Messaging, Admin SDK)
  • Google AdMob (publicidad recompensada)
  • Resend (envío de correos transaccionales)
  • Google Gemini API (asistente de inteligencia artificial)

Puedes consultar las políticas de privacidad de estos servicios en sus sitios web oficiales.

05

Firebase y Analítica

Healtnex utiliza Firebase Analytics de Google para comprender cómo los usuarios interactúan con la App. Esta herramienta recopila datos de uso de forma agregada y anonimizada, incluyendo:

  • Pantallas visitadas y tiempo de uso por módulo.
  • Eventos personalizados (registro de actividades, uso de funciones).
  • Información técnica del dispositivo (modelo, versión de Android, idioma).
  • Datos de instalación y actualizaciones de la App.

Firebase también usa Cloud Messaging (FCM) para enviar notificaciones push al dispositivo. Para ello almacena un token de dispositivo FCM que identifica tu instalación de la App (no tu identidad personal).

Firebase Analytics puede usar el identificador de publicidad de Android (GAID) si está disponible en tu dispositivo. Puedes resetear o deshabilitar este identificador desde Ajustes → Google → Anuncios en tu dispositivo Android.

Política de privacidad de Google/Firebase: policies.google.com/privacy

06

Publicidad — Google AdMob

Los usuarios del Plan Free pueden ver anuncios recompensados a través de Google AdMob. AdMob puede recopilar los siguientes datos para mostrar publicidad relevante:

  • Identificador de publicidad de Android (GAID).
  • Dirección IP aproximada (para geolocalización general).
  • Información del dispositivo (modelo, versión de SO).
  • Datos de interacción con los anuncios.
Healtnex no comparte datos de salud con AdMob. La información de tus registros de salud, actividad física o bienestar no se usa para personalizar la publicidad mostrada en la App.

AdMob puede usar estos datos para mostrarte anuncios personalizados en función de tus intereses según el historial de publicidad de Google. Si prefieres no recibir anuncios personalizados:

  • Ve a Ajustes → Google → Anuncios en tu dispositivo Android.
  • Activa «Inhabilitar personalización de anuncios».

Política de privacidad de AdMob: support.google.com/admob

08

Cómo Controlar el Seguimiento

Tienes varias opciones para controlar el uso de tecnologías de seguimiento en Healtnex:

Deshabilitar la personalización de anuncios Ve a Ajustes → Google → Anuncios en tu Android y activa «Inhabilitar personalización de anuncios». Seguirás viendo anuncios pero no serán personalizados.
Resetear el identificador de publicidad (GAID) En la misma pantalla de Ajustes → Google → Anuncios puedes resetear tu ID de publicidad, lo que desvincula tu historial de anuncios previo.
Desactivar notificaciones push Ve a Ajustes → Aplicaciones → Healtnex → Notificaciones y desactívalas. Esto no afecta el token FCM almacenado, pero no recibirás notificaciones.
Eliminar tu cuenta Desde la configuración de la App puedes eliminar tu cuenta permanentemente. Esto borra todos tus datos personales y el token FCM de nuestros servidores.
Las tecnologías estrictamente necesarias (AsyncStorage para sesión y JWT) no pueden desactivarse sin afectar el funcionamiento básico de Healtnex. Si las eliminas manualmente desde los ajustes del sistema, deberás iniciar sesión nuevamente.
